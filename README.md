# 🧪 Laboratorio: Temas Varios

**Fecha:** 19/10/2026

## 📚 Resumen del Repositorio

En esta practica se abordaron diversos ejercicios practicos desarrollados en C#, orientados a consolidar conceptos clave como operaciones CRUD, consultas a base de datos, buenas practicas de seguridad, Programacion Orientada a Objetos (POO), manejo de recursividad y analisis de frecuencias.

El repositorio incluye la resolucion de cinco puntos principales:

* 🗄️ Consultas SQL
* 🔐 Manipulacion de Cadenas, CRUD y Consultas Parametrizadas
* 🧩 Sobrecarga de Métodos
* 🔄 Cálculo del Factorial mediante Recursividad
* 📊 Analisis y Conteo de Frecuencias

---
